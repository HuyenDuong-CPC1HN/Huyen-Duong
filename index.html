Không mở được app từ file HTML

Đây là app Vite + React. Mở trực tiếp index.html (đường dẫn file://) sẽ ra màn trắng/đen vì trình duyệt không chạy được module /src/main.jsx.

  1. Trong thư mục project, chạy:
npm install npm run dev

Rồi mở đúng URL Vite in ra (thường là):

http://localhost:5173/

Local cần có .env.local với VITE_SUPABASE_URL và VITE_SUPABASE_ANON_KEY (copy từ Supabase / Vercel). Mẫu: .env.example.
